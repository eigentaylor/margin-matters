2028 Campaign Simulator

A single cycle, simulated properly — correlated polling error, a campaign that converges, then election night.
Beta (v0.9). Still in beta. The model is deliberately tunable and not yet calibrated to anyone's satisfaction — see docs/utils/sim2028/.
Setup
Everything is seeded — the same seed always produces the same election. The true result is hidden until election night; you only see polls.

October 19, 2025

Bellwethers

  • Added a new display mode: "Outcome Table (Streaks)".
  • Rather than looking at states/units which are barometric bellwethers (states close to the national popular vote), this table shows states/units that have had long streaks of voting for the winning presidential candidate.
  • Users can set a streak threshold (default 5 elections) and choose to allow up to one or two misses in the streak.
  • The table lists states/units that meet the criteria, showing their longest qualifying streaks, as well as the most recent streak.
  • Allow users to view popular vote winner streaks or electoral vote winner streaks.
  • Added a reverse streaks option to show states that have consistently voted against the winning candidate.

Laplace

  • Added a little naive Monte Carlo simulation tool to estimate probabilities based on Laplace smoothing.
  • Users can set the number of simulations to run.
  • The results table shows the likelihood of each state to be a tipping point based on a simplified Normal model using Laplace probabilities.
  • Clicking on these states brings up a detailed view with more information: showing the differences between a scenario's map at the tipping point and the 2024 map, as well as a basic ranking of states by their relative margin in the scenario.
  • Also included is a table showing the percent of simulations a state was a bellwether within 5 percentage points of the national popular vote and the percentage of simulations it was more democratic than the national popular vote.
  • There are still some bugs and rough edges to work out, but it's a start.

General

  • Updated the PV Presets dropdown to correct the 2024 Trump margin preset from R+1.6 to R+1.5.

October 17, 2025

Data

  • Added EV-orthogonalized presidential margins to the presidential margins dataset.
  • These margins represent each state's margin after removing the national EV-weighted average margin for that year.
  • This gives a slightly different perspective, similar to the relative margin but weighted by EVs instead of turnout.
  • Both the raw EV-orthogonalized margin and its delta from the previous election are included.
  • Updated the build script to compute and include these new margins.

Ranker

  • Added support for EV-orthogonalized margins as a metric in the Ranker tool.
  • Users can now select EV-orthogonalized margin or its delta when ranking states.
  • The display format matches other margin metrics, showing both delta and raw values appropriately.

Laplace

  • Added EV-orthogonalized margin as an available metric in the Laplace tool for analysis, similar to the median delta mode.
  • Set this as the default mode for determining success in the Laplace tool.

Future

  • Set the Election Data Service projection as the default value for the EV Projection, as well as defaulted to only applying for years after 2030.
  • Added a light pull towards bellwether status for states. This is a minor adjustment to fix an issue where if too many bellwethers roll the same direction in Laplace mode, it can result in too few bellwethers.

Index and Future

Future:

  • Added a Laplace method to generate future endpoints (set as default)
  • This uses a Bayesian approach similar to the Laplace page to give a more probabilistic estimate of future margins (allowing for uncertainty). Ex. CA trended blue significantly until 2020, but has started to trend red. But the line of best fit still has a firmly positive slope. Thus, the old method would almost certainly predict a continued blue trend, unless you used a different slope method. Whereas the Laplace method gives about a 50:50 chance of CA trending either direction, by weighting by recency and giving some uncertainty.

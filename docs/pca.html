Methodology
  • Only "state-level" units are included by default: the 50 states + DC, with Maine and Nebraska represented by their statewide (at-large) totals. Enable "Split ME/NE districts" to swap those two states' totals for their congressional-district-level results instead, when the selected range fully supports it (Maine from 1972, Nebraska from 1992).
  • A unit is only included if it has a value for every year in the selected range — no imputation. That's why the default 1964–2024 range gives exactly 51 units (every state + DC has a result in every one of those elections), while an earlier start year can drop states that joined the union or weren't tracked yet (e.g. Alaska/Hawaii before 1960, DC before 1964).
  • Each unit's margin series is standardized (zero mean, unit variance) before PCA, matching the offline pca/do_pca.py pipeline this page mirrors — so components reflect co-movement in trend, not just which states have the widest margins.
  • Loadings are shown correlation-style (component direction scaled by the square root of its explained variance), matching pca/do_pca.py's convention.
  • Varimax rotation redistributes the loadings to be more concentrated (each component leans on fewer states), which usually makes the loadings map easier to read at the cost of components no longer being strictly ordered by variance explained.
  • The reconstruction and historical-error map modes both reconstruct a margin vector from a truncated set of component scores — the same underlying computation either way, just fed hypothetical (slider) scores or a real year's actual scores.
  • When the metric is a relative margin, the reconstructed values represent lean relative to an assumed national environment (adjustable), not an absolute winner — set "Assumed national margin" to translate that into an electoral college outcome.

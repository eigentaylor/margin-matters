Laplace Succession Analyzer

Estimates probability of a positive “move” using Laplace’s rule of succession across multiple window sizes, then combines them with a weighted average.
When enabled, the delta threshold slider is hidden and success is determined by comparing a unit's delta to that year's median delta distance (field: median_delta_dist).
Weight formula: 1 / (1 + λ*(N - minN))

Notes:
• Units are filtered by absolute end-year margin <= absolute threshold. Ex. 0.15 would mean all units within 15 pps of the national popular vote.
• Laplace probability for a window size N is (k+1)/(N+2), where k = number of positive deltas above (>) the threshold in the last N elections for a unit.
• Weighted probability averages across the selected windows using the chosen weight scheme.

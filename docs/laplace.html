Laplace Succession Analyzer

Estimates probability of a positive “move” using Laplace’s rule of succession across multiple window sizes, then combines them with a weighted average.

Notes:
• Units are filtered by absolute end-year margin <= absolute threshold.
• Laplace probability for a window size N is (k+1)/(N+2), where k = number of deltas > threshold in the last N elections for a unit.
• Weighted probability averages across the selected windows using the chosen weight scheme.

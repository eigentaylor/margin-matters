## Flip scenarios

- The "Dim non-flipped states" effect now fades in smoothly instead of snapping instantly, matching the existing fill/glow transitions. This also fixed districts (ME/NE) never having any transition at all.
- When dim is on, clicking a flip button now dims the non-flipped states *first*, then changes the flipped states' color and glow a beat later, instead of both happening at once.
- Fixed a bug where that staged dim-then-flip sequencing silently collapsed back to simultaneous specifically when generating GIFs with `--transition-ms` (the default for `tools/generate_flip_gif.mjs --dim`), due to a CSS computed-style quirk when a single transition-duration override applies to multiple transitioned properties.

## 2028 Simulator

- Custom candidate portraits can now be pasted from the clipboard, not just uploaded or dragged in: a "Paste image" button reads an image straight off the system clipboard, and Ctrl+V works too while focus is anywhere in that candidate's box (e.g. the name field)
- The trend-chart mode "Six closest states" and "All states polling within 5 points" now always include Arizona, Georgia, Wisconsin, Nevada, Michigan, Pennsylvania, and North Carolina if they're available, even in cycles where they aren't currently among the closest-polling states — these perennial battlegrounds are pinned alongside whichever states are most competitive at any given moment

## Election Night

- A dramatic full-screen "Breaking News" flash now plays for a beat before a key-race call, any correction or retraction, the call that actually clinches/loses a majority, or the final-tally/no-longer-decided moments - like a broadcast cutting to a big-story sting before revealing the result
- Within a single state-call popup batch, these "breaking" slides are now grouped and shown first ("we can now call Georgia for Biden - also, Trump wins North Dakota and Wyoming"), so the flash above only has to play once per batch instead of once per key race; the always-final "Final tally" screen still always shows last
- The "Races to watch" list - both the checkpoint popup's slide and the always-on sidebar - now pins key races (states predicted close pre-election, or genuinely close in the true result even when the pre-election signal missed it) to the top, each marked with a small "KEY" tag, ahead of the existing live-drama-based ordering
- In the 2028 simulator, the seven perennial battleground states (Arizona, Georgia, Wisconsin, Nevada, Michigan, Pennsylvania, North Carolina) are always marked with the KEY tag in the "Races to watch" list, ensuring they're always visually highlighted as marquee races even in scenarios where they might not otherwise qualify by the closeness scoring
- Fixed a bug where a state predicted comfortable but that actually ended up razor-thin (e.g. New Mexico in 2000, Michigan in 2016) could be skipped for "key race" emphasis entirely, since the emphasis was based only on the (occasionally noisy) pre-election prediction; it's now based on whichever of the prediction or the true result was closer
- Fixed a bug where the specific call that pushed a candidate over the top (or knocked them back below a majority) could itself display as a routine, unmarked call even though the very next screen announced them winning the presidency, with the electoral vote scoreboard not yet reflecting the majority - that deciding call is now always treated as breaking news itself, and always grouped immediately before the win announcement it caused
- Any correction or retraction is now always treated as breaking news (previously only when the state itself was independently a "key race")
- Removed the separate "Final" flash text for the night's final-tally screen - it now just says "Breaking News" like every other flash, instead of a distinct label that read oddly on its own

## Election Night: Retraction Drama & Lead-Change Alerts

- Toned down how big a wrongly-leaning state's initial called margin could get (e.g. Florida 2000 called for Gore) - it had drifted up to an implausible ~D+11; it's back to the believable ~D+4-5 range it had before
- Added drama to the "too close to call" period after a state gets retracted: most of the time now, once a state is un-called, the count swings toward its TRUE eventual winner with a fresh, sizeable lead that agonizingly narrows back down to the real final margin as counting finishes (the "Bush surges to +10,000, then it shrinks to 537" effect) - the old slower "creep from wrong to right" still shows up occasionally for variety
- Added "Breaking News" alerts for key races when the raw vote lead changes hands while a race is still uncalled - before its first call, or during too-close-to-call limbo after a retraction - mirroring a broadcast flashing a lead change (e.g. "takes the lead in Georgia"); these can pop up as their own standalone checkpoint during a quiet stretch, but don't clutter the persistent call log

## Election Night: Polls Closing

- The state-call checkpoint popup can now show a "Polls just closed" card listing every state whose polls closed at that moment (with each state's electoral vote count and a running total) - it slots into the existing checkpoint schedule alongside call/correction cards rather than forcing a dedicated interruption, so it usually rides along with whatever calls are already happening right after that poll-closing wave, and only appears on its own during a genuine lull (e.g. Alaska/Hawaii at 1am ET)
- Also included in the Election Night Album's generated image set and its captions

## Election Night: Album

- Added an "Election Night Album" button to the election night controls: it silently replays the whole night and generates a shareable set of images - every state-call/correction/retraction/lead-change/outcome card plus a map snapshot after each round of calls - shown in a popup gallery with "Copy" (paste straight into a chat, e.g. Discord) and "Download" buttons per image
- Each card is now drawn directly from that call's own data (state, time, electoral votes, projected winner's photo/name/party, vote-by-candidate rows with margin/raw votes/percent, percent counted) rather than screenshotted from the on-screen popup, so every image comes out the same crisp, fixed size no matter the browser window or zoom level
- The running national electoral-vote tally (with a "+N" chip for whichever party just moved) is now baked into every card's own footer instead of living in a separate on-screen sidebar - and the win-probability readout that used to sit there is dropped, since it didn't add much to a static image
- A routine state call now reads "Projected winner" rather than "Winner," reserving "Winner" for the outcome/final-tally cards where the result is mathematically settled, not just a confidence-threshold projection
- Moved the popular-vote badges (Dem/Other/Rep/Margin/Total) above the electoral-vote-by-rating breakdown on the election night map panel
- Changed the wording of the initial outcome message from "X clinches the presidency" to "X is projected to win the presidency" — the "clinches" language is now reserved for the final tally once every state has actually been called, so the initial announcement matches how preliminary it really is
- The National Popular Vote can now be retracted ("too close to call") just like any state, using the same hysteresis logic: once confidence collapses below a fraction of the call threshold, it un-calls and becomes available to be re-called later if confidence recovers
- Win-probability calculation is now more "naive" and responsive to what's visible on screen: it samples each remaining state independently from its currently observed margin, using only basic polling error, instead of applying regional correlation, historical elasticity, and other statistical sophistication that can dampen dramatic-looking scenarios into hedged forecasts. The forecast still does Monte Carlo but now "believes" what it sees on the map more readily
- A fully-counted unit never flips in the win-probability calculation even if the call was wrong — mirrors how a called unit is fixed, so a corrected call's actual winner stays locked once its own count finishes

## Election Night

- Bumped the sim2028 beta version label from "v0.9" to "v0.9.1".
- Added attribution credits on the Data Sources & Attribution page for the photos used as Nathaniel Sliver's (a new pundit character, still in development) and Aleck Lickman's portraits.
- Added Nathaniel Sliver's first live commentary, a second election-night pundit alongside Aleck Lickman - sim2028 runs only, for now. He narrates the live swing-vs-prior signal already computed to drive the win-probability line (national, regional, and per-key-race), speaking only in magnitude words ("a real move toward the Republican in the Rust Belt") rather than a percentage, and only when a swing crosses a new notability threshold - so he stays occasional and doesn't repeat himself. Dialogue is placeholder/generic for now (his character voice isn't settled yet); a toggle ("Show Nathaniel Sliver commentary") sits next to the existing Lickman toggle on the sim2028 election-night panel. Unlike Lickman, he's deliberately gated off of a real historical-year replay, since a historical replay's "pre-election polling" is a synthesized stand-in for the real thing, not an actual poll - narrating swing-vs-polls off of fabricated data would misrepresent what people actually expected going into that election.
- Fixed a bug where Aleck Lickman's closing "final word" slide could show a literal `{loser}` placeholder instead of his predicted loser's name, when the beets got both the popular vote and the electoral college wrong. The line's template needed a `loser` name but the code building it only ever passed `winner`/`actualWinner`/`beets`.
- Fixed Nathaniel Sliver still naming an already-called state, sometimes repeatedly, instead of focusing on whatever's still genuinely live - his "skip already-decided races" check was checking a field that never actually got set, so it silently never excluded anything (and a fully-counted race's swing reading can look enormous purely because there's so little uncertainty left in it, so this bug tended to crowd out real live contests rather than just occasionally slip one in). He can now also react to the national popular vote moving or getting called, not just state key races - using the same bias-corrected national swing estimate that already drove his existing commentary, since reading the raw running vote count directly would be skewed by which states happen to have reported so far.

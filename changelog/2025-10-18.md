## Bellwether & Close States Explorer
- Added URL parameters for pre-selecting categories, display, and year in the Bellwether & Close States Explorer tool. Users can now share specific views by including parameters in the URL.
  - example: `?year=2004&category=bellwether&display=histogram`
- Showed more detailed margin information (both Raw and Relative margins)
- Made the detailed table more compact by combining certain columns and adding additional context such as electoral votes next to state abbreviations.
- Added streak information to the detailed table view, showing 
  - how many consecutive elections a state has been a bellwether
  - the range of years and length for that streak
  - the last streak the state had before its current status
- Displayed the thresholds as a percentage (e.g., "5.0%") instead of a decimal (e.g., "0.05") for better user clarity.
- Updated visualization titles to include the selected threshold values for better context.
